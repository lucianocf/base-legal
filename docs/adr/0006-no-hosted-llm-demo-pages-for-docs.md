# 0006. No hosted LLM demo in the MVP; GitHub Pages for docs and evals

- Status: Proposed
- Date: 2026-09-26

## Context
A hosted demo maximizes reach, but it costs money per query, attracts abuse
and makes the maintainer a **controller** of any personal data typed into it
(requiring a privacy notice and a RIPD). The budget is close to zero. GitHub
Pages is free but serves only static files, so it cannot run the backend.
A Pages site calling a user's `localhost` API is increasingly blocked by
browsers' private network access protections.

## Decision
- **MVP:** no hosted LLM demo. The README shows a GIF/asciinema recording and
  a 3-command local quickstart; the MCP server works locally with Claude
  Desktop and Claude Code.
- **GitHub Pages (MkDocs Material)** publishes documentation, ADRs, the
  threat model and the **latest eval report** generated by CI.
- **Phase 2:** a static corpus explorer on Pages (client-side search, no LLM).
- **Phase 3:** a hosted demo, treated as a full privacy dogfooding case.

## Consequences
- ➕ Zero cost and zero abuse surface, with no personal data processed by the maintainers.
- ➕ A public link at launch (Pages) that already shows quality (evals, threat model).
- ➖ Non-technical DPOs cannot try it without Docker. Partly mitigated by the
  MCP server and the recording.
