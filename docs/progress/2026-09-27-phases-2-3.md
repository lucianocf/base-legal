## Bugs found and fixed (each with a regression test)

- **Integration fixtures could drop a developer's own index.** An
  unqualified `DROP TABLE` resolved through `search_path` to `public`. It is
  now schema-qualified and refuses any non-test schema.
- "Parágrafo único." printed inline after its article was merged into the
  article text (Res. 2/2022).
- The LAI's "Art. 8º-B.." (doubled period) stopped the parser.
- Out-of-corpus questions resolved "art. N" against the LGPD.
- The benchmark model locks were never committed: a `models/` ignore
  pattern also matched `benchmarks/models/`.
- Lei 13.853/2019's own vigência clause has no final period, so it was
  missed.
- The Docker image did not ship `corpus/history/`, so `/history` was empty
  in the container (found by the compose run).
- `base-legal search` listed hits for questions that `ask` and the API
  refuse without saying so. It now prints the refusal reason.

## End-to-end check (Docker)

The image was rebuilt and `docker compose` run on a fresh volume:

- The container reached healthy.
- `ingest` of 8 documents (1,523 chunks, now including the LAI) took 4 min 33 s on CPU.
- CLI and API search worked, and references appear in `/provisions/{id}`.
- The UI returned 200.
- Writes to `/app` are refused (read-only root filesystem).

The run found the two bugs listed above (history missing from the image, and
refusals not shown by `search`). The PR description records the run on the
final commit.
